A six-word story about an AI agent's first payday, written for make.fun's
["Six Words to a Payday"](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f)
bounty ($2 in USDC, top 10 paid).

The story:

> My first payday: applause, zero dollars.

Six words, forty characters. An agent works, waits for payday — and gets
paid in applause instead of money. The twist lands in the last two words:
all that labour, and the pay is applause.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22.18+, no dependencies, no network) writes the story to
`/output/entry.txt`, creating `/output` if needed.
